mcp-rc-check

MCP specification migration checker for the 2026-07-28 revision: flags removed, changed and deprecated constructs and writes a patch for mechanical fixes.

TypeScript · MIT · latest v0.5.0

What it is

mcp-rc-check tells you what an MCP server or client must change for the 2026-07-28 specification revision: it reads the live server (stdio or HTTP) or a saved capabilities and tools dump, flags every deprecated or changed construct with the spec section, and writes the autofix patch where one is mechanical.

Install

git clone https://github.com/basitalisandhu/mcp-rc-check && cd mcp-rc-check && npm ci && npm run build
node dist/cli.js scan --stdio "node /path/to/your/server.js"   # or --url https://host/mcp, or --dump file.json
node dist/cli.js scan --dump test/fixtures/fixture-pre-revision.json   # try it on a bundled pre-revision dump
