scp-guardrails

Build AWS service control policies from a short spec and lint them for lockouts and statements that deny nothing.

Python · MIT · latest v0.3.0

What it is

scp-guardrails builds AWS Organizations service control policies from a short spec (region allowlist, protected roles, deny leaving the org, deny disabling CloudTrail and GuardDuty, deny root, require IMDSv2, deny public S3 ACLs, spend denies) under the SCP size limit, lints existing SCPs for the mistakes that lock you out or do nothing, and runs as a GitHub Action.

For cloud and platform engineers who run multi-account AWS organizations, and for whoever reviews SCP changes. Quick start (Python 3.11 or newer; the second line fetches the example spec):

pipx install git+https://github.com/basitalisandhu/scp-guardrails
curl -fsSLO https://raw.githubusercontent.com/basitalisandhu/scp-guardrails/main/examples/spec.yaml
scp-guardrails build --spec spec.yaml --out scps && scp-guardrails lint scps/
