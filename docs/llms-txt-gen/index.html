llms-txt-gen

Generate llms.txt for any docs site or repository.

Python · MIT · latest v0.3.0

What it is

Generate llms.txt for any docs site or repository: point llms-txt-gen at a directory of Markdown or HTML, or at a sitemap URL, and it writes an llms.txt (and, with --full, an llms-full.txt) that follows the convention published at llmstxt.org. It also checks an existing file against that convention and prints the HTML tag that tells crawlers where the file lives. Standard library only, no model in the loop, deterministic output, runs in CI.

Who it is for: maintainers of documentation sites and open-source repositories who want their docs to be read well by AI assistants and coding agents, and who want the file rebuilt in CI rather than kept by hand. Project site: https://basitalisandhu.github.io/llms-txt-gen/.

Install

pipx install git+https://github.com/basitalisandhu/llms-txt-gen

llms-txt-gen generate docs/ --out llms.txt --base-url https://docs.example.com
llms-txt-gen generate https://docs.example.com/sitemap.xml --out llms.txt --full
llms-txt-gen check llms.txt
llms-txt-gen serve-snippet
