claude-perm-sim

Claude Code permission rule simulator: shows which rule decides a tool call and where a rule set is permissive.

TypeScript · MIT · latest v0.3.1

What it is

claude-perm-sim loads your merged Claude Code permission settings, tells you which rule decides any given tool call, and finds the bypasses: commands that slip past a Bash pattern, paths that escape an Edit scope, and MCP tools nothing covers.

For developers and teams who hand-write Claude Code permission rules. Read-only, no runtime dependencies, Node 20 or newer. Part of a small set of Claude Code security tools listed at basitalisandhu.github.io, alongside agent-config-audit and cc-plugin-lock.

Install

npx github:basitalisandhu/claude-perm-sim load                               # effective rules, with the file each came from
npx github:basitalisandhu/claude-perm-sim explain "Bash(git push origin main)"  # which rule decides one call
npx github:basitalisandhu/claude-perm-sim bypass                             # where an allow rule admits more than it names
