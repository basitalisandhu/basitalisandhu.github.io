# Changelog

All notable changes to this site and its generator. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [Unreleased]

## [0.2.0] - 2026-10-16

### Added

- `/tools/` page: every repository grouped by theme, with its one-liner and install command, and `CollectionPage` and `ItemList` JSON-LD. Linked from the navigation, the footer, the home page, `sitemap.xml` and `llms.txt`.
- Default Open Graph image (`sitekit/og-default.png`, 1200x630, generated by `scripts/make_og_image.py`) served as `/og.png`; every page now carries `og:image` with size and alt text, `og:locale` and a `summary_large_image` Twitter card with title, description and image.
- Internal links: posts list the tools they link to ("Tools in this post") and up to five more posts; project pages list the posts that mention them and the other projects in the same theme.
- JSON-LD: the home page `Person` has `jobTitle`, `knowsAbout` and `sameAs` (GitHub and dev.to); posts add `image`, `publisher`, `isPartOf` and `mentions` for the tools they link to.
- `robots.txt` names the search and user-triggered fetchers as well as the training crawlers (OAI-SearchBot, ChatGPT-User, Claude-SearchBot, Claude-User, Perplexity-User, Googlebot, Bingbot, Applebot, Applebot-Extended, CCBot), all allowed.
- Checks: `og.png` and `tools/index.html` must exist, `og.png` must be a PNG, and every HTML page must carry `og:image`.

### Changed

- Meta and social descriptions are cut to 160 characters at a sentence or word boundary; JSON-LD keeps the full description.
- Project page titles include the one-liner when the result stays within 70 characters; the posts index has a real description.

## [0.1.0] - 2026-10-04

### Added

- Standard-library generator (`build.py`, `sitekit/`) with a small Markdown converter, writing `docs/`: home page (bio, four themed project tables, latest releases, packages link, posts), one page per repository with `SoftwareSourceCode` JSON-LD, posts with `BlogPosting` JSON-LD, posts index, `404.html`, `sitemap.xml`, `robots.txt` (AI crawlers allowed by name), RSS `feed.xml` for posts and releases, `llms.txt`, `llms-full.txt`, `.nojekyll` and the IndexNow key file.
- `scripts/sync_repos.py`: refreshes `data/repos.json` from the GitHub API and the profile README.
- Site checks: HTML well-formedness, JSON-LD, internal links and anchors, sitemap and llms.txt targets, robots.txt, IndexNow key, and house style (no em-dashes, no model names, blocklisted words).
- Workflows: `ci` on pull requests, `pages` deploy with an IndexNow ping of changed URLs, daily `sync` pull request. Actions pinned by SHA; Dependabot for actions.
- First post: "Four open repositories for securing AI agents, and what each is for".
